Hisab 0.4 — UI and setup revision
Online skills reviewed and applied as design guidance (no global skill installation or UI framework dependency):
https://github.com/KrickmanC/ui-ux-pro-max/blob/main/SKILL.md
https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md

Theme.xaml provides semantic colors and native WPF control templates. UiTheme handles Windows high-contrast colors. Controls preserve native combo/calendar popups and keyboard behavior. Large 54-pixel form targets, 56-pixel table rows, persistent field labels, automation names and amber focus outlines improve readability and use.
The home screen has four everyday actions. Advanced tools are grouped separately. Arabic RTL and English LTR are supported; 24-point text and a 1024x768 window were visually checked. Narrower windows stack action cards. Full OS assistive-technology/high-contrast/DPI testing remains to be done on real target devices.
Personal setup creates no user-facing account. It uses an internal owner identity for audit/permissions. Optional lock: 4+ characters, existing password hashing and failed-attempt lockout. Optional shared named user passwords: 8+ characters. Portable backup passwords: 10+ characters, unchanged. Anyone using the same unlocked Windows profile can open direct personal mode.
Setup-Guide-Arabic.pdf is a three-page printable illustrated guide, rendered with native Arabic shaping. QUICKSTART-AR.txt supplies selectable Arabic instructions.
