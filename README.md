# حساب — Hisab

برنامج حسابات مكتبي لويندوز، بالعربية مع خيار الإنجليزية. البيانات محفوظة محليًا، ولا تحتاج إلى تثبيت قاعدة بيانات أو إنشاء حساب للاستخدام الشخصي.

## تنزيل البرنامج وفتحه

1. افتح **Releases**، ثم أحدث إصدار.
2. تحت **Assets** اضغط **Hisab-Windows.zip** وانتظر اكتمال التنزيل.
3. افتح مجلد **التنزيلات / Downloads** على الكمبيوتر.
4. اضغط بزر الفأرة الأيمن على الملف، ثم اختر **استخراج الكل / Extract All**.
5. افتح المجلد المستخرج، ثم افتح **Start-Hisab.cmd** بنقرتين.
6. اكتب اسم المحل إن أردت، واختر حجم الخط، ثم اضغط **ابدأ استخدام البرنامج**.
7. افتح **Setup-Guide-Arabic.pdf** الموجود في المجلد لشرح تجهيز العملاء والأصناف وأول فاتورة وحفظ نسخة احتياطية.

لا تحتاج إلى Git أو أوامر clone. ملف **Hisab-Windows.zip** في الإصدار يحتوي البرنامج الجاهز للتشغيل. خيار **Code → Download ZIP** وملفات **Source code (zip)** تحتوي ملفات التطوير.

## الإصدار ٠٫٣

- واجهة عربية من اليمين إلى اليسار، مع الإنجليزية والخط الكبير.
- فتح مباشر للاستخدام الشخصي، مع رمز فتح اختياري.
- فواتير بيع وشراء، سندات قبض وصرف، شيكات، مخزون، مرتجعات وتقارير.
- قاعدة بيانات محلية مشفرة ونسخ احتياطية محمولة بكلمة مرور.
- نسخ Windows x64 وx86 وARM64، يختارها ملف التشغيل تلقائيًا.

اجتاز الإصدار ٩١ فحصًا على كل من x64 وx86. جرى بناء نسخة ARM64، ولم تُختبر على جهاز ARM. الملفات التنفيذية غير موقّعة بشهادة توقيع برامج. الطباعة على طابعة فعلية واستخدام جهاز آخر يحتاجان إلى تحقق. تصدير ضريبة المبيعات الأردنية ورقة للمراجعة؛ ليس إقرارًا مقدمًا إلى الدائرة.

لا يتضمن الإصدار معاملات تجريبية أو قاعدة بيانات المستخدم. يتضمن الأسماء الأصلية للعملاء والموردين والأصناف بإذن صاحب المشروع.

## Development

C# / .NET 10 / WPF, SQLite, encrypted local snapshots. The release includes `Source.zip`, architecture and validation notes, and third-party notices. See `source/build.ps1` for Windows builds.
